# 🛂 Smart Visitor Management System

A full-stack web application to manage and track visitors in an organization. Features include visitor registration, check-in/check-out logging, employee notifications, QR code badge generation, and visit history.

---

## 📁 Project Structure


---

## 🚀 Features

### ✅ Visitor Features
- Register new visitors
- Check-in & Check-out system
- Auto-generated visitor badges with QR codes

### 🧑‍💼 Admin/Employee Features
- View visitor history
- Assign employees to visitors
- Email notifications to hosts
- Export visit logs (PDF/Excel)
